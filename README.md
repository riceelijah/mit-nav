# MIT Navigator

Step-by-step directions across MIT, from building to building and floor to floor, with a step-free option. It grew out of a Simmons Hall navigator; every building, Simmons included, is now generated from MIT's room inventory. Sign in with your MIT class account (Commons) or a username and password to report problems and to keep favorites, saved trips, preferences, and a trip journal. Anyone can flag a passage (for example an elevator) as blocked, and everyone's directions avoid it until someone marks it clear. See `design/` for the concept and composition specs.

## Run it

```sh
bun install
bun run dev        # starts MongoDB (podman), backend :3000, frontend :8080
bun run seed       # in a second terminal, with the backend stopped, to load or update the map
```

## Updating the campus map

`data/campus.json` and the floor plans in `web/plans/` are generated by `bun run campus` from inputs in `data/raw/`. `data/raw/` is never committed or put in the Docker image, because MIT Facilities data is for internal use. The generated files are committed because the app needs them to route and draw plans; they hold room numbers, uses, sizes and positions derived from that data, so keep the repository private and ask MIT Facilities (fis-request@mit.edu) before publishing it.

- `data/raw/rooms/<building>.csv`: the room inventory for one building. Sign in at floorplans.mit.edu, open Room Inventory → By Building → the building, and press "Report Download". Save it as `<building>.csv` (for example `32.csv`).
- `data/raw/osm.json`: OpenStreetMap building footprints, downloaded automatically on the first run.
- `data/raw/relative-room-locations.json`: where each room, corridor, elevator and stair is on MIT's floor plans. Sign in at mitmapit.org, open https://mitmapit.org/api/relative-room-locations, and save the page. Optional: without it, every floor is a single corridor.
- `data/raw/paths.json`, `streets.json`, `entrances.json`, `centers.json`, `whereis.json`: footpaths, street names and entrances (OpenStreetMap), building centres (MapIT) and names (whereis.mit.edu), downloaded automatically.
- `data/raw/pdfs/<building>_<floor>.pdf` (optional): MIT's floor-plan drawings from floorplans.mit.edu. `python3 scripts/fit-drawings.py` fits each to the map and writes `data/raw/drawings/`; the page then offers "MIT drawing" for those floors on this machine only.

Each building becomes a place at its main entrance, joined to OpenStreetMap's footpaths, sidewalks and crosswalks, so outdoor walks follow real paths. A building with a room list also gets each floor's corridors at their real positions, its elevators and stairs, and its rooms, with walking distances. Touching buildings are joined on a floor where both have a corridor reaching the shared wall, and corridors within 15 m (bridges) are joined too. After regenerating, stop the backend and run `bun run seed` again: it updates the map in place, so accounts, favorites, saved trips, history and blocked passages are kept (favorites and trips of rooms that left the map are removed).

Open http://127.0.0.1:8080. `bun test` runs the tests on an in-memory MongoDB (no setup needed; the first run downloads a MongoDB binary); `bun run test:real` runs them against the container database after `bun run db:up`. `bun run db:reset` empties the database, accounts included.
